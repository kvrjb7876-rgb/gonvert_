GONVERT — photo folder (pharma)
==============================================================

Each .jpg in this folder (and in the services/ folder) is a
PLACEHOLDER currently showing on the website.

TO PUT A REAL PHOTO ON THE SITE:
  1. Rename your photo to EXACTLY the name of the file you
     want to replace  (e.g. hero.jpg)
  2. Drag it into this folder and choose "Replace"
  3. Publish the site

The name and the .jpg ending must match exactly.
Each placeholder has its own file path printed on the image,
so open one to see which page it belongs to.

Full instructions: HOW-TO-ADD-IMAGES.md in the main folder.
